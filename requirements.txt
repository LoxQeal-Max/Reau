# 录制自动化插件 - uiautomator2 方案
# ============================================================
# 录制自动化插件 - 使用说明
# ============================================================
#
# 【环境要求】
#   - Python 3.8 或更高版本
#   - Android 手机 (开启 USB 调试)
#   - USB 数据线连接电脑
#
# 【安装依赖】
#   命令行执行: pip install -r requirements.txt
#
# 【启动方式】
#   方式一 (推荐): 双击 "启动录制工具.bat"
#   方式二: 命令行执行: python gui/main.py
#
# 【功能说明】
#   - 开始录制: 点击 "● 开始录制" 按钮，然后在手机上操作
#   - 结束录制: 点击 "■ 结束录制" 按钮
#   - 回放脚本: 选择历史会话，点击 "▶ 回放" 按钮
#   - 停止回放: 点击 "■ 停止" 按钮
#
# ============================================================
