# Reau - Android 自动化测试工具
# ============================================================
# 使用说明
# ============================================================
#
# 【环境要求】
#   - Python 3.8 或更高版本
#   - Android 手机 (开启 USB 调试)
#   - USB 数据线连接电脑
#
# 【安装依赖】
#   命令行执行: pip install -r requirements.txt
#
# 【启动方式】
#   双击 "启动Web版.vbs" 或执行: python start.py
#
# 【访问地址】
#   打开浏览器访问: http://localhost:8000
#
# 【功能说明】
#   - 设备管理: 连接/断开设备，查看屏幕预览
#   - 录制回放: 录制操作、回放脚本、支持循环
#   - AI Agent: AI 自动执行任务
#   - 实时日志: 查看所有操作日志
#
# ============================================================
